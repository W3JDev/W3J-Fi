# Backend (Symfony) - Coming Soon

The Symfony backend for real-time polls is planned for future implementation.

## Current Status
The frontend works in **local-first mode** without a backend. Polls are stored in localStorage.

## Planned Features
- Symfony 7.2 + PHP 8.3
- Doctrine ORM with SQLite
- REST API endpoints
- Server-Sent Events (SSE)
- Anti-cheat mechanisms
- Rate limiting

## Frontend Still Works!
The application is fully functional without the backend:
- Polls stored locally in browser
- All features work offline
- Perfect for demos and testing

## Future Implementation
To contribute to the backend:
1. Check CONTRIBUTING.md
2. Follow Symfony best practices
3. Maintain API compatibility with frontend
